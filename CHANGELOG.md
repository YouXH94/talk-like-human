# Changelog / 版本记录

## v1.0.0 — 2026-10-26

### 中文

- 首次公开发布 `talk-like-human` 中文写作技能。
- 包含核心指令、Codex 显示信息与默认允许自动选用的调用策略。
- 保留六组虚构中文案例，涵盖问题解释、未完成检查、测试条件、产品规则、进度风险和重复操作。
- 提供中英文使用说明、三组前后对比、固定版本安装方法及 MIT 许可证。
- 发布可直接解压安装的 ZIP 包及 SHA-256 校验文件。

示例用于解释表达方式，不是实际项目记录或模型效果评测。

### English

- First public release of the `talk-like-human` skill for Chinese explanatory writing.
- Includes core instructions, Codex UI metadata, and automatic selection enabled by default.
- Retains six fictional Chinese examples covering problem explanations, incomplete checks, test conditions, product rules, schedule risks, and duplicate work.
- Adds Chinese and English guides, three before-and-after comparisons, pinned installation instructions, and an MIT license.
- Provides an installable ZIP archive and SHA-256 checksum file.

Examples illustrate writing choices; they are not real project records or model benchmarks.
